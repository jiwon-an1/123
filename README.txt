우선도착 — ACO 응급차 경로 학습 실험실

실행: index.html을 더블클릭하여 브라우저에서 여세요.
index.html, engine.js, app.js를 같은 폴더에 보관하세요.
설치, 서버, 인터넷 연결, 외부 라이브러리가 필요 없습니다.

1. 탐색 재생: 반복당 여러 개미의 이동을 보여줍니다. 같은 버튼으로 일시정지합니다.
2. 한 단계 진행: 한 반복을 완료합니다. 일시정지 중인 반복이 있으면 해당 반복을 완료합니다.
3. 지도 도로 또는 드롭다운 선택: 길이, 속도, 신호 대기, 혼잡 배수, 통제 변경.
4. B 경로 사고·혼잡 예시: 모든 도로를 초기 예시로 복원한 뒤 B2에 혼잡을 적용합니다.
   A 12분, B 17분, C 11분이 되어 C가 최소시간 경로가 됩니다.
5. 초기화: 도로, 탐색 설정, 비교와 기록을 모두 처음으로 되돌립니다.
6. 기록의 반복/개미 버튼: 각 교차로에서 실제 사용한 선택 확률을 확인합니다.

시간 단위: 분 = km / (km/h) × 60 + 신호 대기 초 / 60.
유효속도 = 예상 주행속도 / 혼잡 배수.
재생 배속은 애니메이션에만 적용하며 계산 시간에는 영향이 없습니다.
도로/ACO 설정 변경은 탐색을 중지하고 페로몬 1과 빈 기록으로 새로 시작합니다.
ACO는 무작위 알고리즘이므로 실행마다 탐색 결과가 다를 수 있습니다.
이 도로망은 세 후보를 비교하는 교육용 양방향 그래프입니다.
실제 지도, 실시간 교통정보, 실제 응급차 안내를 제공하지 않습니다.
